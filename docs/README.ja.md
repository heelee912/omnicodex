# OmniCodex 日本語ガイド

OmniCodex は、インストール済み Codex ランタイムの実際のツールを、所有者
認証付き MCP として公開します。Codex デスクトップ、認証、設定、ローカル
MCP 登録には干渉しません。`npm install -g @heelee912/omnicodex` の後、`omnicodex init`
と `omnicodex doctor` を使用してください。Oracle 補助機能は既定で dry-run
であり、明示された loopback CDP にのみ接続し、Connect と Always allow 以外
をクリックしません。詳細は英語 README、PRD、reference ledger を参照してください。
