# OmniCodex 中文指南

OmniCodex 将已安装 Codex 运行时的真实工具公开为仅限所有者的认证 MCP。
它不会控制 Codex 桌面应用、修改认证或配置，也不会把 OmniCodex 注册到本地
Codex MCP。使用 `npm install -g @heelee912/omnicodex`、`omnicodex init` 和
`omnicodex doctor` 完成安装与检查。Oracle 辅助功能默认 dry-run，只连接明确
配置的 loopback CDP，并且仅处理 Connect 和 Always allow。安全边界与来源归属
请参阅英文 README、PRD 和 reference ledger。
